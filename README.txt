Prepared 16 October 2026

WHAT IS IN THIS FOLDER

  index.html        Home
  about.html        About BioInfoX and About the founder
  services.html     The eight service lines
  training.html     Latest training (Cohort 3) and previous trainings
  team.html         Team and advisors
  research.html     Selected publications
  contact.html      Contact details and project brief form
  founder.html      Full profile of Muhammad Nouman Majeed
  404.html          Page shown when a link is broken

  assets/css        Styles (style.css for all pages, founder.css for the founder page)
  assets/js         Menu, copy buttons, project brief form, publication search
  assets/img        Logos, photo, favicons and the social sharing image

  favicon.ico       Browser tab icon
  site.webmanifest  Icon and colour settings for phones
  robots.txt        Tells search engines they may index the site
  sitemap.xml       List of pages for Google Search Console
  .htaccess         Https, error page and speed settings for Apache hosting
                    (hidden on Mac: press Cmd + Shift + . in Finder to see it)

CLAUDE.md         Internal project notes for further editing. Do NOT upload it
                    to your hosting (it is blocked by .htaccess if you do).

PREVIEW ON THIS MAC

  Double-click index.html. Every menu item opens its own page.

PUT IT ONLINE (choose one)

  A) Shared hosting with cPanel (Hostinger, Namecheap, local Pakistani hosts)
     1. Open File Manager and go to public_html.
     2. Upload everything inside this folder, including the hidden .htaccess file.
     3. Visit https://www.bioinfoxlab.org to check.

  B) Netlify (free)
     1. Go to app.netlify.com/drop and drag this whole folder onto the page.
     2. In Site settings > Domain management, add bioinfoxlab.org and follow
        the DNS instructions shown there.

  C) GitHub Pages (free)
     1. Create a repository, upload the contents of this folder.
     2. Settings > Pages > Deploy from branch (main, root).
     3. Add bioinfoxlab.org as the custom domain.

AFTER LAUNCH

  1. Turn on https (free SSL) in your hosting panel.
  2. Add the site to Google Search Console and submit sitemap.xml.
  3. Share the home page link once on LinkedIn to check the preview image.

UPDATING

  Text lives in the .html files and can be edited in any text editor.
  When the next training is announced, update training.html and the
  "Latest training" block on index.html.
